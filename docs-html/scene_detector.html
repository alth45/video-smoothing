scene_detector

Deteksi pergantian scene (cut) dengan menghitung korelasi histogram grayscale antar dua frame berurutan. Digunakan untuk mencegah optical flow mencoba menginterpolasi antara dua shot yang tidak berhubungan.

sceneDiff() function

double sceneDiff(const cv::Mat& a, const cv::Mat& b)

Menghitung korelasi histogram 64-bin dari dua frame.

Parameter

ParamTipeDeskripsi
acv::MatFrame sebelumnya (BGR)
bcv::MatFrame berikutnya (BGR)

Return

Nilai korelasi [−1, 1]. Semakin tinggi = distribusi intensitas makin mirip. Threshold di PipelineOptions.sceneThresh (default 0.4) memisahkan "same scene" vs "cut".

Interpretasi nilai

NilaiArtiAksi pipeline
> 0.7Hampir sama (frame diam)Interpolasi normal
0.4 – 0.7Same scene, gerakan aktifInterpolasi normal
0.2 – 0.4Kemungkinan transisi/fadeTergantung threshold
< 0.2Cut / shot baruDuplikasi prev (skip interpolasi)

Algoritma

// 1. Konversi ke grayscale
gray_a = cvtColor(a, BGR2GRAY)
gray_b = cvtColor(b, BGR2GRAY)

// 2. Hitung histogram 64-bin, range [0,256)
hist_a = calcHist(gray_a, 64 bins)
hist_b = calcHist(gray_b, 64 bins)

// 3. Normalisasi L1 supaya total = 1 (probabilitas)
normalize(hist_a, NORM_L1)
normalize(hist_b, NORM_L1)

// 4. Correlation
return compareHist(hist_a, hist_b, HISTCMP_CORREL)

Mengapa histogram, bukan pixel-difference?

MetodeKelebihanKelemahan
Mean absolute difference Simpel Sangat sensitif ke gerakan kamera/objek — false positive tinggi
Histogram correlation Tahan terhadap translasi (warna tetap sama meski piksel geser), hanya berubah drastis saat cut Tidak mendeteksi cut antara dua scene dengan palet warna sama

Karena kita peduli gerakan (yang justru tidak ingin dianggap cut), histogram correlation adalah trade-off yang tepat.
