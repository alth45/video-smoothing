util

Utilitas kecil yang tidak bergantung pada modul lain. Saat ini hanya satu fungsi: format durasi.

formatDuration() function

std::string formatDuration(double sec)

Format detik ke string human-readable. Skema:

Range detikContoh output
negatif / > 1e9"--"
< 1.0"<1s"
1 – 59"12s", "45s"
60 – 3599"3m 24s"
≥ 3600"1h 05m"

Contoh

formatDuration(0.5)    // "<1s"
formatDuration(12.3)   // "12s"
formatDuration(204.7)  // "3m 24s"
formatDuration(3925)   // "1h 05m"
formatDuration(-5)     // "--"

Dependency & Penggunaan

Tidak bergantung ke modul lain. Dipakai oleh:

pipeline.run → untuk cetak waktu proses & ETA
Rencana ke depan: modul ini bisa menampung helper lain seperti formatBytes(), splitExtension(), trimQuotes(). Karena tidak ada dependency, aman untuk di-extend.
