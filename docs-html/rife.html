RIFE (AI Frame Interpolation)

⚠ EXPERIMENTAL — KODE BELUM TERUJI

Implementasi RIFE ini belum diuji oleh developer karena tidak ada hardware GPU tersedia. Kode disertakan sebagai referensi dan siap dipakai, tapi kualitas, stabilitas, dan performa tidak dijamin.

Untuk mengaktifkan, wajib pakai flag --ai-experimental. Flag lama --ai sudah deprecated dan akan menolak jalan.

Real-time Intermediate Flow Estimation — model neural network yang menghasilkan frame interpolasi kualitas sinematik. Jauh lebih halus dari Farneback/DIS untuk gerakan besar dan tepi objek.

Butuh model ONNX (~50–80 MB) yang tidak disertakan. Lihat download-rife.sh untuk cara memperolehnya.

RifeInterpolator class

RifeInterpolator(const std::string& modelPath, int mult = 2)

isReady() / error()

Setelah konstruksi, cek isReady(). Kalau false, error() berisi pesan penyebab (model tidak ada / format salah).

processPair()

std::vector<cv::Mat> processPair(const cv::Mat& prev, const cv::Mat& next) override

Untuk tiap frame interpolasi t = i/mult, jalankan satu forward pass model dengan input (prev, next, t).

Model yang didukung

Tipe ModelInputmult
RIFE v4.6 (3-input)img0, img1, timestep2, 3, 4, …
RIFE lain (2-input)img0, img12 (t=0.5 only)

Cara Pakai

# Siapkan model
./download-rife.sh

# Jalankan dengan AI
./video_flow_smooth -i in.mp4 -o out.mp4 -m 2 --ai

# Custom model path
./video_flow_smooth -i in.mp4 -o out.mp4 -m 3 --ai --rife-model models/custom.onnx

Troubleshooting

ErrorSolusi
"Gagal load model ONNX"File rusak / format salah. Pastikan hasil export dari RIFE v4.x
"Model tidak punya 2 atau 3 input"Input name tidak dikenali. Coba export ulang dengan nama standar (img0, img1, timestep)
"Model 2-input hanya mendukung t=0.5"Pakai model 3-input (RIFE v4.6) untuk mult > 2
"Forward pass gagal saat init"Inisialisasi model bermasalah. Cek versi OpenCV (butuh ≥ 4.5)
