ffmpeg_helper

Wrapper seluruh interaksi dengan executable FFmpeg/FFprobe. Menangkap stdout (untuk ffprobe) dan stderr (untuk error), lalu menampilkan error 1-baris + pesan ramah saat gagal.

ffmpeg::run() function

CmdResult run(const std::string& cmd)

Menjalankan command via system(), redirect stdout & stderr ke file temp, baca hasilnya, lalu hapus file temp. Mengembalikan CmdResult yang terisi lengkap.

Deteksi error fatal pakai hasCriticalFfmpegError dengan pattern seperti "Error submitting packet", "Invalid data found", "moov atom not found", dst.

Dipanggil oleh semua fungsi lain di halaman ini.

ffmpeg::showFriendlyError() function

void showFriendlyError(const CmdResult& r, const std::string& stageName, const std::string& inputFile)

Menampilkan:

  1. [!!] GAGAL: <stageName>
  2. [ffmpeg] <firstErrorLine> — 1 baris asli dari ffmpeg
  3. Blok saran: cek VLC, update ffmpeg, atau --no-audio

Caller tinggal return 1 setelah memanggil fungsi ini.

ffmpeg::extractAudio() function

AudioStatus extractAudio(const std::string& video, const std::string& outAudio)

3 langkah:

  1. Probe via ffprobe: cek stream audio ada/tidak. Kalau exit code ≠ 0 → error fatal → showFriendlyError → return Failed.
  2. Kalau tidak ada stream audio (codec_name kosong / N/A) → return NoAudio (normal, bukan error).
  3. Ekstrak: ffmpeg -vn -c:a aac -b:a 192k. Kalau gagal → Failed. Sanity-check ukuran file ≥ 1024 byte.

ffmpeg::muxAudio() function

bool muxAudio(const std::string& videoOnly, const std::string& audioFile, const std::string& finalOut)

Gabung video + audio dengan re-encode H.264 (-crf 18 -preset medium) dan -shortest supaya durasi pas. Re-encode diperlukan karena intermediate dari OpenCV mungkin codec-nya tidak universal.

Kalau gagal → tampilkan error → return false (pipeline akan fallback ke remuxVideoOnly).

Dipanggil oleh pipeline.run tahap 3.

ffmpeg::remuxVideoOnly() function

bool remuxVideoOnly(const std::string& videoOnly, const std::string& finalOut)

Stream copy (-c copy) tanpa decode/encode ulang. Cepat tapi hanya bekerja kalau codec intermediate sudah universal.

Digunakan sebagai fallback saat muxAudio gagal, atau saat file tidak punya audio.

Pola Error Handling

Sukses: fungsi return nilai normal (OK / true), pipeline lanjut.
Gagal fatal: tampilkan 1 baris error + saran → return Failed / false → pipeline return 1. Tidak ada loop error panjang.
