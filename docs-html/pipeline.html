pipeline

Orkestrasi seluruh proses: ekstrak audio → frame interpolation → mux audio → summary. Modul ini yang memutuskan urutan, membuka/menutup resource, dan melaporkan error ke user.

run() method

int run() // 0 = sukses, 1 = gagal

Melakukan 4 tahap berurutan. Kalau ada tahap gagal, langsung return 1 tanpa lanjut.

Tahap 1 — Ekstrak audio

  1. Cek ffmpeg::isAvailable. Kalau tidak ada → warning, lanjut tanpa audio.
  2. Kalau skipAudio → skip tahap ini.
  3. Panggil ffmpeg::extractAudio. Kalau hasilnya Failed → bersihkan file setengah jadi dan return 1.

Tahap 2 — Frame interpolation

  1. Buka VideoCapture. Baca fps, W, H.
  2. Buka VideoWriter ke file temp (mp4v, fallback MJPG .avi).
  3. Buat FlowInterpolator dengan parameter dari options.
  4. Loop tiap pasangan frame:
    • Kalau sceneDetect aktif, panggil sceneDiff. Kalau corr < sceneThresh → duplikasi prev sebanyak mult (tanpa interpolasi).
    • Kalau tidak cut → FlowInterpolator::processPair, tulis semua frame hasil.
    • Update progress bar tiap 10 frame.
  5. Setelah loop, tulis frame terakhir sekali lagi (supaya durasi pas).

Tahap 3 — Mux audio

  1. Kalau ada audio + ffmpeg: ffmpeg::muxAudio.
  2. Kalau gagal mux (tapi video OK): fallback ffmpeg::remuxVideoOnly.
  3. Kalau tidak ada ffmpeg sama sekali: fs::copy_file langsung.
  4. Hapus file intermediate.

Tahap 4 — Summary

Cetak ke stdout: input frame, output frame, fps, jumlah scene cut, rata-rata occlusion %, waktu proses (pakai formatDuration), status audio, path file output.
