Termux / Android

Panduan menjalankan Video Flow Smooth di Android tanpa root, via Termux.

Performa mobile: CPU Snapdragon/MediaTek modern (misalnya Snapdragon 8 Gen 2) memproses ~2–5 fps untuk video 1080p dengan --dis. Video 5 menit ≈ 20–30 menit proses. Gunakan --dis dan hindari -m 4 untuk hemat waktu.

Prasyarat

  1. Install Termux dari F-Droid (versi Play Store sudah usang).
  2. Buka Termux, tunggu hingga prompt muncul.

Setup Akses Storage

Agar bisa baca/tulis ke folder Downloads, DCIM, dsb. (lokasi /sdcard/):

termux-setup-storage

Android akan menampilkan dialog izin — izinkan.

Setelah itu, folder-folder umum tersedia di ~/storage/:

Path TermuxLokasi Android
~/storage/shared/sdcard/
~/storage/downloadsDownload
~/storage/dcimDCIM (kamera)
~/storage/moviesMovies

Install Dependencies

pkg update -y
pkg install -y cmake clang make opencv ffmpeg

Ukuran ~500 MB. Install pertama kali bisa 5–15 menit tergantung koneksi.

Build

Script otomatis (install deps + storage + build):

cd ~/video-smoothing        # folder project
chmod +x build-termux.sh
./build-termux.sh

Atau manual:

cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Setelah selesai, binary ada di build/video_flow_smooth dan (kalau script dipakai) juga di $PREFIX/bin/video_flow_smooth.

Menjalankan

Proses video dari folder Download:

video_flow_smooth \
  -i ~/storage/downloads/input.mp4 \
  -o ~/storage/downloads/output.mp4 \
  -m 2 --dis

Dari folder home (tanpa setup storage):

video_flow_smooth -i in.mp4 -o out.mp4 -m 2 --dis

Tuning untuk Mobile

SituasiRekomendasi
Default cepat --dis (wajib di mobile)
Mult 2 sudah cukup -m 2; hindari -m 3+
Hemat baterai --no-occlusion --dis (occlusion ~20% lebih lambat)
Kualitas lebih halus di gerakan cepat Biarkan occlusion ON, tapi siap menunggu lebih lama
4K Downscale dulu ke 1080p dengan FFmpeg:
ffmpeg -i in.mp4 -vf scale=1920:-2 small.mp4
Out of Memory: memproses video 4K langsung di Termux (>2 GB per frame buffer) biasanya menyebabkan OOM kill oleh Android. Selalu downscale dulu.

Jalankan di Background

Supaya proses tetap hidup saat layar mati atau Termux di-background:

# Ambil wakelock (cegah Android sleep)
termux-wake-lock

# Jalankan proses
nohup video_flow_smooth -i in.mp4 -o out.mp4 -m 2 --dis \
  > run.log 2>&1 &

# Pantau
tail -f run.log

# Setelah selesai, lepas wakelock
termux-wake-unlock

Troubleshooting

Error undefined symbol: _ZNSt3__1... saat runtime

ABI mismatch antara libc++ static (default clang) dan libc++_shared (dipakai opencv pkg). Solusinya ada di CMakeLists.txt yang sudah menambahkan target_link_libraries(video_flow_smooth PRIVATE c++_shared).

Kalau masih error, rebuild dari bersih:

rm -rf build
./build-termux.sh --clean

Error OpenCV not found

Pastikan opencv benar-benar terpasang:

pkg install -y opencv
ls $PREFIX/lib/cmake/opencv4/

Kalau folder kosong, coba reinstall: pkg reinstall opencv

FFmpeg tidak ditemukan

pkg install -y ffmpeg
which ffmpeg
# harusnya: /data/data/com.termux/files/usr/bin/ffmpeg

Proses berhenti sendiri saat layar mati

Android membunuh proses background untuk hemat baterai. Gunakan termux-wake-lock (lihat bagian Jalankan di Background) — bagian dari paket termux-api:

pkg install -y termux-api

Baca file dari /sdcard gagal (permission denied)

Jalankan termux-setup-storage dan izinkan dialog Android. Beberapa ROM (MIUI, EMUI) butuh izin tambahan lewat Settings → Apps → Termux → Permissions → Storage.

Output.mp4 kosong / tidak bisa diputar

Codec OpenCV Termux mungkin tidak support H.264 encode langsung. Kode sudah fallback ke MJPG/AVI, tapi kalau tetap gagal:

# Pakai AVI (fallback otomatis)
video_flow_smooth -i in.mp4 -o out.avi -m 2 --dis

# Lalu remux ke MP4 dengan ffmpeg
ffmpeg -i out.avi -c:v libx264 -crf 18 -pix_fmt yuv420p out.mp4

Dengan Farneback (default), sekitar 3–5× lebih lambat. Untuk video 5 menit (9000 frame di 30 fps → 30 menit proses pada 5 fps), sebaiknya potong dulu dengan FFmpeg atau proses sambil tidur.
