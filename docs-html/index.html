Video Flow Smooth

Tool command-line C++ untuk menaikkan frame rate video dengan optical flow frame interpolation — menghasilkan gerakan jauh lebih halus, dilengkapi scene-change detection, occlusion masking, dan pemrosesan audio otomatis via FFmpeg.

Arsitektur

Setiap modul punya satu tanggung jawab. Panah = dependency.

Modul

main.cpp

Entry point. Parsing argumen CLI, validasi, meneruskan ke pipeline.

pipeline

PipelineOptions dan VideoSmoothingPipeline — orkestrasi 4 tahap.

flow_interpolator

FlowInterpolator — optical flow, occlusion mask, blending adaptif.

scene_detector

sceneDiff() — deteksi scene cut via histogram correlation.

ffmpeg_helper

Wrapper FFmpeg: capture error, extract audio, mux, remux.

util

formatDuration() — format detik ke string human-readable.

Quick Start

# Build
cmake -B build -S . -G "Visual Studio 17 2022" -A x64 -DOpenCV_DIR=C:/opencv/build
cmake --build build --config Release --parallel

# Jalankan: 30fps → 60fps
build\Release\video_flow_smooth.exe -i input.mp4 -o output.mp4 -m 2

# Slow-mo 4x dengan DIS optical flow (lebih cepat)
build\Release\video_flow_smooth.exe -i input.mp4 -o output.mp4 -m 4 --dis

Alur Pemrosesan (4 Tahap)

TahapAksiModul
1/4 Probe & ekstrak audio ke audio/<stem>_audio.m4a ffmpeg::extractAudio
2/4 Frame interpolation loop + scene detection pipeline.run, FlowInterpolator, sceneDiff
3/4 Mux audio + video → output final ffmpeg::muxAudio
4/4 Tampilkan summary (frames, fps, waktu, occlusion %) formatDuration
