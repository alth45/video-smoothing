flow_interpolator

Inti teknis: menghitung dense optical flow dua arah, membangun occlusion mask via forward-backward consistency, lalu menghasilkan frame interpolasi dengan blending adaptif.

FlowInterpolator class

FlowInterpolator( int mult = 2, float smoothSigma = 1.5f, bool useFarneback = true, bool useOcclusion = true, float occlusionThresh = 2.0f )
ParameterDeskripsi
multJumlah frame per pasangan (prev + mult-1 interpolasi)
smoothSigmaσ Gaussian blur pada flow. 0 = tidak dihaluskan
useFarnebacktrue = Farneback (halus), false = DIS (cepat)
useOcclusionAktifkan occlusion masking
occlusionThreshAmbang magnitude FB-consistency (piksel). Makin kecil → makin banyak area dianggap occluded

processPair() method

std::vector<cv::Mat> processPair(const Mat& prev, const Mat& next)

Menghasilkan mult frame: [prev, interp1, interp2, …, interp(mult-1)].

  1. Panggil computeFlows → dua flow (forward & backward).
  2. Kalau smoothSigma > 0, blur kedua flow (Gaussian).
  3. Kalau useOcclusion, bangun computeOcclusionMask untuk kedua arah, update lastOcclusionRatio_.
  4. Untuk i = 1..mult-1, panggil interpAt.

computeFlows() method (private)

void computeFlows(const Mat& a, const Mat& b, Mat& f_ab, Mat& f_ba)

Hitung flow dua arah. Konversi ke grayscale dulu untuk kecepatan.

  • useFarneback_ == true → calcOpticalFlowFarneback dengan param (0.5, 5, 21, 3, 7, 1.5).
  • useFarneback_ == false → DISOpticalFlow preset MEDIUM.

Output f_ab: flow dari frame A ke B. f_ba: sebaliknya. Tipe CV_32FC2 (per piksel: Point2f = displacement x,y).

warpWithFlow() method (private)

Mat warpWithFlow(const Mat& img, const Mat& flow, float scale)

Warp image dengan remap menggunakan map: map(x,y) = (x - scale·flow_x, y - scale·flow_y).

scale = t → titik di frame A "bergeser" ke posisi pada waktu t. scale = 1-t dengan flow backward → titik di frame B "bergeser mundur" ke posisi yang sama pada waktu t.

warpMaskWithFlow() method (private)

Mat warpMaskWithFlow(const Mat& mask, const Mat& flow, float scale)

Sama seperti warpWithFlow tapi khusus untuk mask CV_8U. Pakai BORDER_CONSTANT 0 supaya piksel di luar frame otomatis dianggap "tidak reliable".

Interpolasi INTER_LINEAR membuat tepi mask soft (255 → 128 → 0), sehingga blending di tepi tidak tajam.

computeOcclusionMask() method (private)

Mat computeOcclusionMask(const Mat& f_ab, const Mat& f_ba, float thresh)

Forward-backward consistency check. Untuk tiap pixel (x,y): 

v     = f_ab(x, y)
b     = f_ba( (x + v.x), (y + v.y) )   // bilinear sample
error = |v + b|
mask(x,y) = (error < thresh) ? 255 : 0
  • error kecil → flow konsisten (bukan occlusion) → reliable (255).
  • error besar → titik "hilang" karena tertutup objek → unreliable (0).
  • Piksel di luar frame saat sampling → otomatis 0.

interpAt() method (private)

Mat interpAt(const Mat& prev, const Mat& next, const Mat& f_ab, const Mat& f_ba, const Mat& maskPrev, const Mat& maskNext, float t)

Menghasilkan satu frame interpolasi pada waktu t ∈ (0,1).

Mode tanpa occlusion (mask kosong)

Sederhana: result = (1-t)·warpPrev + t·warpNext.

Mode dengan occlusion (mask tidak kosong)

  1. Warp kedua mask dengan warpMaskWithFlow.
  2. Konversi ke [0,1], beri epsilon 1e-3 (cegah weight 0 mutlak).
  3. Weight dasar:
    • w_p = reliabilityPrev · (1-t)
    • w_n = reliabilityNext · t
  4. Normalisasi: w_p / (w_p + w_n) dst.
  5. Blending per-pixel dengan weight 3-channel.

Efek: di area occluded (salah satu mask 0), weight frame itu ~0 → hasilnya hanya dari frame yang reliable, bukan blend 50/50 yang menghasilkan ghosting.

lastOcclusionRatio() method

float lastOcclusionRatio() const

Rata-rata % piksel yang dianggap occluded dari panggilan processPair terakhir. Rentang 0.0–1.0. Digunakan pipeline.run untuk statistik summary.

Interpretasi: 2–8% = normal (gerakan moderat). > 20% = threshold mungkin terlalu ketat, naikkan --occ-thresh.

Rumus Matematis

Untuk pixel x dan waktu t:

flow_ab(x)    = posisi_x_di_B - posisi_x_di_A
flow_ba(x)    = posisi_x_di_A - posisi_x_di_B

warp_A_t(x)   = A( x - t · flow_ab(x) )
warp_B_t(x)   = B( x - (1-t) · flow_ba(x) )

I_t(x)        = w_A(x)·warp_A_t(x) + w_B(x)·warp_B_t(x)

w_A(x)        = reliability_A(x) · (1-t)
w_B(x)        = reliability_B(x) · t
