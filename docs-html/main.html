main.cpp

Entry point program. Tugasnya hanya dua: parse CLI lalu delegasikan ke pipeline. Tidak ada logika pemrosesan di sini.

main() function

int main(int argc, char** argv)

Alur internal:

  1. Inisialisasi PipelineOptions dengan nilai default.
  2. Loop semua argumen CLI, isi field PipelineOptions sesuai flag.
  3. Validasi: mult ≥ 2, sceneThresh ∈ [0,1], occlusionThresh ∈ [0.1,10].
  4. Validasi: output ≠ input (pakai std::filesystem::absolute).
  5. Bangun VideoSmoothingPipeline, panggil run(), kembalikan exit code-nya.
